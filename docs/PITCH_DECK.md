## Слайд 2 — Проблема
- В Узбекистане миллионы камер. Они **записывают, но не смотрят**.
- Один охранник — 30–40 экранов: физически пропускает почти всё.
- После инцидента: **часы перемотки архива** вручную.
- Камеры без наблюдателя = страховка задним числом, не защита.
- Визуал: фото стены мониторов + таймер «4 часа перемотки».

**Notes:** боль знакома каждому директору. Одна фраза-гвоздь: «Камера видела. Никто не смотрел».

## Слайд 3 — Решение
- AI-аналитик **поверх уже установленных камер** (любой бренд, RTSP).
- Сам следит → **мгновенная карточка в Telegram**: фото, зона, время, клип.
- Отвечает на вопросы на **узбекском и русском**: «Kim kirdi 18:00dan keyin?»
- Находит человека **по описанию внешности** за секунды.
- Каждый вечер — **дайджест дня**.
- Визуал: 3 скриншота бота (алерт с кнопками / диалог / дайджест).

**Notes:** ключевое отличие от «видеоаналитики»: мы автоматизируем не камеры, а принятие решений.

## Слайд 5 — Как это работает (архитектура)
- Схема: Камеры (RTSP/любые) → Детекция+трекинг (YOLO11+ByteTrack) →
  **Rule Engine** (зоны, hysteresis, рабочие часы) → События+клипы (Postgres+кольцевой буфер)
  → **CLIP-поиск по описанию** → **LLM-агент** (SQL-first инструменты) → **VLM-описания кадров**
  → Telegram / дайджест / API.
- Подпись: «6 камер + весь AI-стек — на одном ноутбуке» (факт демо).

**Notes:** для AI-жюри. Подчеркнуть: агент не пишет SQL и не выдумывает — типизированные инструменты.

## Слайд 6 — Полностью офлайн (козырь для госсектора)
- Видео, лица, события — **не покидают объект**.
- LLM-агент и vision-модель — **локальные** (Ollama, qwen2.5): работает с выключенным интернетом.
- Биометрия анонимна по умолчанию, TTL на хранение, «паспорт данных» для юриста.
- Визуал: схема on-prem бокса + перечёркнутое облако.

**Notes:** это ответ на главный вопрос банков/госов. Ни Verkada, ни Hikvision-облака этого не дают.

## Слайд 7 — Инженерная зрелость (не студенческое демо)
- **Калибровка поиска на данных**: реальные совпадения +0.05 от базлайна, отсутствующие −0.02
  → честное «не найдено» вместо «ближайшего попавшегося» (коммит 9f43ed7).
- **Отрицания**: CLIP игнорирует «без» — guard + LLM-переформулировка (2bcfa74).
- **Петля ложных срабатываний**: кнопка «Ложное» → база → тюнинг порогов.
- **Golden-set CI**: каждый пуш гоняет полный пайплайн на эталонном клипе (456c5bb).
- **Ночное исследование**: ИК-камеры — штатно; без ИК — пресет возвращает половину потери (456c5bb).

## Слайд 10 — Бизнес-модель
- Подписка за камеру в месяц (от 30–50 тыс. сум, сегментно) / on-prem лицензия + суппорт.
- **Якорь**: зарплата одного охранника = подписка на 30–50 камер, которые не моргают.
- Канал: **интеграторы-установщики** (тысячи смонтированных камер, % с recurring)
