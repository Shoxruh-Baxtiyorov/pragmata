## Слайд 2 — Проблема
- В Узбекистане миллионы камер. Они **записывают, но не смотрят**.
- Один охранник — 30–40 экранов: физически пропускает почти всё.
- После инцидента: **часы перемотки архива** вручную.
- Камера без наблюдателя = страховка задним числом, не защита.
- Визуал: стена мониторов + таймер «4 часа перемотки».

**Notes:** боль знакома каждому директору. Гвоздь: «Камера видела. Никто не смотрел».

## Слайд 3 — Решение
- AI-аналитик **поверх уже установленных камер** (любой бренд, RTSP) — без замены железа.
- Сам следит и **мгновенно сигналит**: карточка в дашборде и Telegram — фото, зона, время, клип.
- **Диалог на узбекском и русском**: «Kim kirdi 18:00dan keyin?» — отвечает по архиву.
- Находит человека **по описанию внешности** за секунды. Каждый вечер — **дайджест дня**.
- Визуал: три экрана — живая стена / чат-ассистент / карточка события.

**Notes:** отличие от «видеоаналитики»: не ещё один детектор, а copilot-слой поверх любого железа.

## Слайд 4 — Демо

  «kim bu?» в чате → находит по имени (Face ID) → поиск по описанию → вечерний дайджест.
- QR-код на полное 3-мин видео.

**Notes:** если формат позволяет — живое демо на pragmata.uz, слайд как fallback.

## Слайд 5 — Что умеет (каталог, а не одна фича)
Клиент **сам включает нужные модули** на каждой камере/зоне — **19 готовых модулей**:
- **Безопасность:** вход в зону, задержка, присутствие вне рабочих часов, оружие, опасная зона, оставленный предмет, **автономера (LPR)**, неправильная парковка.
- **Ритейл/люди:** подсчёт посетителей, скопление, очередь, **тепловая карта**, **распознавание лиц** (журнал вход/выход по именам).
- **Стройка/склад:** каска и жилет (СИЗ), простой техники, загрузочная зона.
- **Кухня/HORECA:** гигиена (перчатки/шапочка), огонь и дым, повреждение упаковки.

**Notes:** это не демо одной функции — это настраиваемая платформа. Каждый модуль реально работает.

## Слайд 6 — Как это работает (архитектура)
- Камеры (RTSP/любые) → Детекция+трекинг (**YOLO11 + ByteTrack на GPU, реальное время**) →
  **Rule Engine** (зоны, hysteresis, рабочие часы) → События + клипы (Postgres+pgvector, кольцевой буфер)
  → **Распознавание лиц** (InsightFace) + **CLIP-поиск по описанию** + **ANPR** →
  **LLM-агент** (SQL-first инструменты) + **VLM-описания кадров** → Дашборд / Telegram / дайджест / PDF-акт.
- Подпись: «Детекция в реальном времени на GPU. Весь AI-стек — на одной ноде».

**Notes:** для AI-жюри. Агент НЕ пишет SQL и не выдумывает — типизированные инструменты. VLM только на флагнутые события.

## Слайд 7 — Полностью офлайн (козырь для гос/банков)
- Видео, лица, события, номера — **не покидают объект**.
- LLM-агент и vision-модель — **локальные** (Ollama): работает с выключенным интернетом.
- Биометрия анонимна по умолчанию, TTL на хранение, тенант-изоляция данных.
- Визуал: on-prem бокс + перечёркнутое облако.

**Notes:** ответ на главный вопрос банков/госов. Ни Verkada, ни Hikvision-облака этого не дают.

## Слайд 8 — Инженерная зрелость (не студенческое демо)
- **Калибровка поиска на данных**: реальные совпадения +0.05 от базлайна, отсутствующие −0.02
  → честное «не найдено» вместо «ближайшего попавшегося» (коммит 9f43ed7).
- **Отрицания**: CLIP игнорирует «без» — guard + LLM-переформулировка (2bcfa74).
- **Петля ложных срабатываний**: кнопка «Ложное» → база → тюнинг порогов.
- **Golden-set CI** + строгие ворота: ruff, mypy strict, ~90 тестов, контракт OpenAPI на каждый пуш.
- **Тенант-изоляция**: данные организаций не пересекаются (проверено тестами).

**Notes:** «мы знаем, где CV ломается в проде, и уже закрыли». Всё проверяемо в репо.

## Слайд 11 — Бизнес-модель
- Подписка **за камеру в месяц** (сегментно, от ~40 тыс. сум) / on-prem лицензия + суппорт.
- **Якорь**: зарплата одного охранника = подписка на десятки камер, которые не моргают.
- Канал: **интеграторы-установщики** (тысячи смонтированных камер, % с recurring)
  → пультовая охрана → госзакупки (после сертификации).
- Managed on-prem: клиенту — «всё моё на месте», нам — SaaS-экономика (обновления/лицензии из облака).

**Notes:** канал — ключ: не продаём по одной камере, подключаем парки камер интеграторов.
