# Pragmata AI — brand assets

The mark is a **camera aperture** (6-blade diaphragm, 60° symmetry) — «Pragmata sees».

## Files

| File | Use |
|------|-----|
| `pragmata-logo-dark.svg` / `.png` | Full lockup on **dark** backgrounds (mint mark + white wordmark) |
| `pragmata-logo-light.svg` / `.png` | Full lockup on **light** backgrounds (teal mark + charcoal wordmark) |
| `pragmata-mark.svg` | Icon only (aperture) — app icon, favicon, avatar |
| `pragmata-mark-512.png` / `-1024.png` | Rasterized icon (transparent) |

SVG is source-of-truth (recolor / convert text to outlines in any editor). PNGs are transparent, ready for the deck, video and app.

## Colors

| Token | Hex | Use |
|-------|-----|-----|
| Brand teal | `#0D9488` | mark on light backgrounds |
| Brand mint | `#34CBB9` | mark on dark backgrounds |
| Ink | `#0E1621` | wordmark on light backgrounds, dark surfaces |
| Off-white | `#EAF1F6` | wordmark on dark backgrounds |

Wordmark: **PRAGMATA AI**, uppercase, bold, ~0.1em letter-spacing (app uses Plus Jakarta Sans; PNGs rasterized with a metric-compatible bold sans).
